網站：https://cheng-1001.github.io/ArgoStrategyGuide/

資料來源：

- [官方物品圖鑑](https://saominecraft.com/wiki)（物品名稱、稀有度、數值、圖示）
- 玩家提供的遊戲內座標

第 2、3 層為開放前的 wiki 資料，開放後可能變動。
