# 回報表單、審核、自動上線：設定說明

整套做好之後的流程：

1. 玩家在查詢工具的「回報」分頁按「填寫回報表單」，用 Google 帳號登入，填資料、上傳截圖。
2. 回報自動進到「回報審核」試算表，狀態是「待審核」。
3. 審核員看截圖，把「狀態」改成「核准」或「退回」。
4. 核准後，程式自動把截圖和資料送到 GitHub，網站大約 1～3 分鐘後更新。

全部免費，不需要綁信用卡。設定只要做一次，大約 15～20 分鐘。

---

## 步驟一：產生 GitHub 金鑰（約 3 分鐘）

這組金鑰讓 Google 的程式有權限把資料寫進網站，**只限這個 repo 的檔案**，碰不到你其他 GitHub 專案。

1. 用電腦登入 GitHub，打開 <https://github.com/settings/personal-access-tokens/new>
2. 依序填寫：
   - **Token name**：`aincrad-report`
   - **Expiration**：選 `Custom`，日期選一年後（到期後要重新產生，見最下方「金鑰到期」）
   - **Resource owner**：`Cheng-1001`
   - **Repository access**：選 `Only select repositories`，再選 `Cheng-1001/ArgoStrategyGuide`
   - **Permissions**：在「Repositories」分頁按右邊的 **+ Add permissions** → 在清單裡勾選 **Contents** → 關閉清單後，把 Contents 那一列右邊的存取權改成 **Read and write**（Metadata 會自動加上 Read-only，不用動）
3. 按最下面的 **Generate token**，確認後畫面會出現一串 `github_pat_` 開頭的文字。
4. 按旁邊的複製圖示，先貼在記事本裡。**這串文字只會顯示這一次**，離開頁面就看不到了。不要傳給任何人，包括傳到對話裡。

## 步驟二：建立 Google 程式（約 5 分鐘）

1. 用你的 Google 帳號打開 <https://script.google.com>，按左上角 **新專案**。
2. 點左上角「未命名的專案」，改名成 `Aincrad 回報自動化`。
3. 編輯區裡預設有一段 `function myFunction() {}`，全部選取刪掉。
4. 打開 <https://raw.githubusercontent.com/Cheng-1001/ArgoStrategyGuide/main/google/apps-script.gs>，按 **Ctrl+A** 全選、**Ctrl+C** 複製，回到編輯區按 **Ctrl+V** 貼上，再按 **Ctrl+S** 存檔。
5. 點左側齒輪圖示 **專案設定**，捲到最下面 **指令碼屬性** → **新增指令碼屬性**：
   - 屬性：`GITHUB_TOKEN`
   - 值：步驟一複製的那串 `github_pat_…`
   - 按 **儲存指令碼屬性**
6. 點左側 `< >` 圖示回到 **編輯器**。上方工具列的函式選單選 **setup**，按 **執行**。
7. 第一次執行會要求授權：
   1. 跳出「需要授權」→ 按 **審查權限** → 選你的 Google 帳號。
   2. 出現「Google 尚未驗證這個應用程式」→ 按左下 **進階** → **前往「Aincrad 回報自動化」（不安全）**。這是你自己剛建立的程式，所以 Google 沒有審查過，不是病毒。
   3. 看完權限清單（建立表單和試算表、讀取上傳的截圖、連到 GitHub）→ 按 **允許**。
8. 等下方「執行記錄」出現「執行完畢」，會列出三個網址：
   - 表單（編輯）
   - 試算表
   - 預先填好樓層的網址

   這三個網址也存在試算表的「設定資訊」分頁裡，之後隨時可以查。

---

## 步驟三：在表單加上「截圖」上傳題目（約 3 分鐘）

Google 不允許程式建立上傳題目，所以這題要手動加。

1. 打開步驟二的 **表單（編輯）** 網址，捲到最後一個區段「截圖」。
2. 點那個區段，再按右側浮動工具列的 **⊕（新增問題）**。
3. 題型（右上角下拉選單）選 **上傳檔案**，跳出說明時按 **繼續**。
4. 設定這一題：
   - 題目名稱：**截圖**（要一字不差，程式靠這兩個字找到截圖）
   - **只允許特定檔案類型**：打開，勾 **圖片**
   - **檔案數量上限**：5
   - **檔案大小上限**：10 MB
   - 右下角 **必填**：打開
5. 檢查分頁跳轉（程式已經設好，確認一下就好）：
   - 「怪物」區段（第 2 區段）的最底下應該寫「第 2 區段結束後：前往第 5 區段（截圖）」
   - 「物品」區段（第 3 區段）的最底下應該寫「第 3 區段結束後：前往第 5 區段（截圖）」
   - 如果顯示的是「繼續前往下一個區段」，點它改成「前往第 5 區段（截圖）」
6. 表單會自動儲存，不用按存檔。
7. 回到 Google 程式編輯器，函式選單選 **checkSetup** → **執行**。執行記錄出現「設定都正確。」就完成了。如果出現「還缺：…」，照提示補上再執行一次。

---

## 步驟四：把表單網址交給 Claude

打開試算表的「設定資訊」分頁，把 **預先填好樓層的網址** 那一格整串複製，貼到對話裡給 Claude。這個網址只是公開的表單連結，可以放心貼。

Claude 會把它設定到查詢工具的「回報」分頁。玩家按「填寫回報表單」時，樓層會自動帶入目前看的樓層。

---

## 步驟五：加審核員

1. 打開試算表，右上角 **共用**。
2. 輸入審核員的 Gmail，權限選 **編輯者**，按 **傳送**。
3. 審核員只能修改「狀態」和「審核備註」兩欄。其他欄位都鎖住了，看不到也碰不到 GitHub 金鑰。

### 審核員怎麼審

1. 打開試算表的「回報」分頁，找「狀態」是 **待審核** 的列。
2. 點「截圖」欄的連結看截圖，對照同一列填的資料。
3. 「狀態」欄點下拉選單：
   - **核准**：資料和截圖一致。大約 10～30 秒後，「處理結果」欄會顯示「已上線 …」，網站 1～3 分鐘後更新。
   - **退回**：截圖看不出內容，或資料對不上。可以在「審核備註」寫原因。
4. 「處理結果」出現「錯誤：…」時，請通知網站管理者。

## 審核網頁（卡片式審核，手機也好用）

一次看一筆：大張截圖、整理好的資料、座標在地圖上的位置，下面是「✅ 核准」「❌ 退回」按鈕，按完自動跳下一筆。
上方可以切「怪物／物品／地點」和樓層；預設**怪物、物品優先**，同一級由最早送出的先審。「已處理」可以看歷史和上線結果。

**安全設計**：審核網頁是另一個獨立的小專案，用「審核員自己的 Google 帳號」執行，只有試算表的編輯者打得開，
而且只會改「狀態」「審核備註」兩欄。GitHub 金鑰仍然只在「Aincrad 回報自動化」裡；核准後由它每分鐘檢查一次並上線，
所以**核准後最多 1 分鐘才開始上線**。

### 第一部分：更新主程式（約 3 分鐘）

1. 照下方「更新到新版程式」第 1～4 步，重新貼上 `apps-script.gs` 並存檔。
2. 函式選單選 **enableReviewQueue** → **執行**。如果要求授權就按「允許」。
3. 執行記錄會出現：
   - 「每分鐘處理佇列：已啟用。」
   - 「截圖資料夾「…」已分享給：（審核員的 email）」。如果你還沒加其他審核員，會寫「目前沒有其他編輯者」，這是正常的。

### 第二部分：建立審核網頁（約 7 分鐘）

1. 打開 <https://script.google.com> → 左上角 **新專案**，把名稱改成 `艾恩葛朗特回報審核網頁`。
2. 左側齒輪 **專案設定** → 勾選「**在編輯器中顯示「appsscript.json」資訊清單檔案**」。
3. 回到左側 `< >` **編輯器**，點檔案清單裡的 **appsscript.json**：
   - Ctrl+A 全選刪掉。
   - 打開 <https://raw.githubusercontent.com/Cheng-1001/ArgoStrategyGuide/main/google/review.appsscript.json>，全選複製，貼回來，Ctrl+S 存檔。
4. 點 **程式碼.gs**：
   - Ctrl+A 全選刪掉。
   - 打開 <https://raw.githubusercontent.com/Cheng-1001/ArgoStrategyGuide/main/google/review.gs>，全選複製，貼回來。
5. 找到開頭這一行：`const SHEET_URL = '';`
   在兩個單引號中間貼上審核試算表的網址（試算表「設定資訊」分頁第 4 列那個），變成：
   `const SHEET_URL = 'https://docs.google.com/spreadsheets/d/…/edit';`
   按 Ctrl+S 存檔。
6. 右上角 **部署** → **新增部署作業** → 左邊齒輪選 **網頁應用程式**，填寫：
   - 說明：`審核網頁`
   - 執行身分：**存取網頁應用程式的使用者**
   - 誰可以存取：**擁有 Google 帳戶的任何使用者**（真正的限制是試算表權限：不是編輯者的人打開只會看到「打不開審核試算表」）
7. 按 **部署**。要求授權時照之前的方式按「審查權限 → 選帳號 → 進階 → 前往…（不安全）→ 允許」。
8. 複製畫面上的 **網頁應用程式網址**（`https://script.google.com/macros/s/…/exec`），打開就是審核網頁。
   建議把這個網址貼到試算表「設定資訊」分頁第 6 列，方便審核員找。

### 新增審核員

1. 試算表右上角 **共用** → 輸入對方的 Gmail，權限選 **編輯者** → 傳送。
2. 回到「Aincrad 回報自動化」執行一次 **enableReviewQueue**（把截圖資料夾分享給他，他才看得到截圖）。
3. 把審核網頁網址給他。他第一次打開時，Google 會要他授權，並顯示「Google 尚未驗證這個應用程式」：
   這是你自己建立的程式，沒有送 Google 審查才會這樣顯示。按「進階 → 前往 艾恩葛朗特回報審核網頁（不安全）→ 允許」即可。
   授權內容是：讀寫他自己有權限的試算表、唯讀他看得到的雲端硬碟檔案（用來顯示截圖）、讀他的 email（記錄是誰審核的）。

### 審核網頁之後要更新時

貼上新的 `review.gs`（記得重新填 `SHEET_URL`）→ 右上角 **部署** → **管理部署作業** → 鉛筆 **編輯** → 版本選 **新版本** → **部署**。網址不會變。


### 更新到新版程式（GitHub 上的 apps-script.gs 有改動時）

程式放在你的 Google 帳號裡，GitHub 上的檔案更新後不會自動同步，要照下面重新貼一次。金鑰、表單、試算表、觸發器都不受影響。

1. 打開 <https://script.google.com> → 專案「Aincrad 回報自動化」。
2. 在編輯區按 **Ctrl+A** 全選，按 Delete 刪掉舊程式。
3. 打開 <https://raw.githubusercontent.com/Cheng-1001/ArgoStrategyGuide/main/google/apps-script.gs>，**Ctrl+A**、**Ctrl+C**，回到編輯區 **Ctrl+V**，再按 **Ctrl+S** 存檔。
4. 上方函式選單選 **upgradeSheet** → **執行**。如果跳出授權視窗，照步驟二第 7 點按「允許」（這版多用到「在試算表插入圖片」）。
5. 執行記錄出現「審核畫面已更新：N 筆回報。」就完成了。
6. 同時，表單「截圖」那一頁的說明也會換成 F2 截圖教學（檔案位置、怎麼一次選多張、不要按 F1）。打開表單預覽就看得到。

### 審核畫面（執行過 upgradeSheet 之後）

- 「回報」分頁只留下審核要看的欄位：**回報編號｜截圖預覽｜內容摘要｜狀態｜審核備註｜處理結果**。
- **截圖預覽**：第一張截圖直接顯示在格子裡，不用點連結。有多張時，摘要最後會寫「截圖 N 張」，其他張點表單原始的「截圖」欄連結看。
- **內容摘要**：回報種類、樓層、名稱和玩家填的每個欄位（例如「等級：3」「座標 x, z：1340, 3569」）整理成一格。
- **整列顏色**：待審核＝黃、核准＝綠、退回＝紅，一眼看出還有哪些沒審。
- 表單的原始欄位被收起來了。要看的話，點欄位字母上方的 **＋** 展開，看完再按 **−** 收回。
- 審核方式不變：在「狀態」下拉選單選 **核准** 或 **退回**。

如果某列的截圖預覽顯示「開啟截圖（預覽失敗…）」，通常是 Google 雲端硬碟還在產生縮圖。等幾分鐘後再執行一次 **upgradeSheet** 就會補上，或直接點連結看截圖，不影響核准。


### 金鑰到期（或處理結果出現「GitHub 金鑰無效或已過期」）

1. 照步驟一重新產生一組金鑰。
2. Google 程式 → 專案設定 → 指令碼屬性 → 編輯 `GITHUB_TOKEN`，換成新的值。
3. 編輯器選 **retryApproved** → **執行**。所有核准但還沒上線的回報會一次補送。

到期期間送來的回報都會留在試算表裡，不會遺失。

### 想新增或調整表單題目

- **新增題目**：直接在表單加。新題目的答案會一起存進網站。要顯示在工具的哪裡，請告訴 Claude 調整網站。
- **改題目名稱、刪題目**：先告訴 Claude。網站是靠題目名稱判斷內容的，例如「怪物・等級」。
- **不要改**：「回報種類」「樓層」「名稱」「截圖」這四題的名稱，以及試算表的「回報編號」「狀態」「審核備註」「處理結果」四欄的名稱。

### 處理結果一直停在「處理中…」

通常是同時核准太多筆，等一分鐘再看。還是沒有變化的話，到 Google 程式編輯器執行 **retryApproved**。
